Linode（Akamai）VPS评测：老牌厂商还能打吗

2026年1月18日
VPS评测 Linode Akamai

Linode的前世今生

Linode成立于2003年，算是VPS行业的老前辈了。2022年被CDN巨头Akamai收购后，品牌逐渐转型为”Akamai Cloud Computing”。不过大家还是习惯叫它Linode。

我从2021年就开始用Linode，经历了收购前后的变化。总体来说，产品本身没有大的退步，但也没有让人眼前一亮的进步。

性能测试

测试机器是东京机房的Nanode 1GB（$5/月）。

sysbench cpu --cpu-max-prime=20000 --threads=1 run

events/s: 3012.56

CPU性能中等偏上，比DO的Basic好一些，比Vultr的High Frequency差一些。日常使用完全没问题。

IO性能比预期好。Linode这几年一直在升级存储硬件，从以前的SAS升到了全NVMe。

Geekbench

这个分数在$5档VPS里算合格。

东京机房网络测试

这应该是国内用户最关心的。Linode东京机房（Tokyo 2）表现：

运营商延迟晚高峰延迟丢包率
电信92ms110ms0.8%
联通86ms98ms0.5%
移动105ms145ms2.1%

电信和联通的表现还不错，移动就差一些了。晚高峰虽然延迟会涨，但不像美国机房那么夸张。在没有CN2的情况下，东京机房对国内算是比较友好的了。

traceroute分析

电信走的是NTT线路到日本，然后走Akamai的骨干网。联通走的也是NTT。线路不算差，但也不是最优。

Akamai收购后的变化

好的变化

  • 新增机房：增加了雅加达、金奈、米兰等机房
  • 网络升级：接入了Akamai的全球骨干网
  • DDoS防护：集成了Akamai的DDoS防护能力

不太好的变化

  • 品牌混乱：到处都是”Akamai Cloud Computing (formerly Linode)“，看着很别扭
  • 面板改版：新面板不如旧版简洁，有些功能找不到了
  • 价格没降：收购这么久了价格一分没降，有点失望

使用体验

控制面板

新版面板（Cloud Manager）基于React构建，功能还算全面但加载速度有点慢。创建实例、管理DNS、配置防火墙这些基本操作都有。

StackScripts

类似DO的一键安装，但更灵活。你可以写自己的部署脚本，也可以用社区分享的。对于自动化部署来说挺方便的。

客服

Linode的客服一直不错，工单回复通常在1-4小时内。而且技术水平比较高，不是那种只会发模板回复的。

适合谁

  • 需要东京机房的用户：Linode东京机房表现稳定
  • 看重客服质量的用户：Linode的技术支持确实好
  • 长期稳定使用的用户：Linode跑了20多年了，不用担心跑路

不适合预算很紧的用户，同样的钱在RackNerd能买到更多配置。如果你在犹豫选哪家，看看海外VPS推荐对比。

想知道VPS买来第一步应该做什么，可以看安全初始化指南。

总结

Linode是一家靠谱的老牌VPS厂商，被Akamai收购后产品质量保持稳定。东京机房对国内访问友好，客服质量上乘。但价格在2026年来看不算便宜，性能也不是最强的。总的来说是个稳妥但不惊艳的选择。

评分：7/10
